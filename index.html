三、南京市会展政策

3.1 会展业扶持政策

  • 场馆租金补贴：对在南京举办的国际性展会，给予场馆租金50%补贴
  • 大型展会奖励：展览面积超过5万平方米的展会，给予最高200万元奖励
  • 新办展会扶持：首次在南京举办的国际性展会，给予最高100万元启动资金
  • 品牌展会培育：连续举办3年以上的展会，每年给予运营补贴

3.2 申报条件

  • 在南京市注册的会展企业
  • 展会实际展览面积达到一定规模
  • 展会符合南京市产业发展方向
  • 展会取得良好的经济和社会效益

3.3 申报流程

  1. 展会结束后30日内提交申报材料
  2. 南京市商务局初审
  3. 第三方机构评估
  4. 公示
  5. 资金拨付

📚 会议会展行业知识库

一、活动策划核心方法论

1.1 5W2H分析法

要素内容关键问题
Why活动目的为什么要办这个活动？
What活动主题活动是什么？核心内容是什么？
Who参与人员谁来参加？目标受众是谁？
When时间安排什么时候办？持续多久？
Where地点选择在哪里办？场地要求？
How执行方式怎么办？流程是什么？
How much预算花多少钱？投入产出比？

1.2 活动策划六步法

  1. 需求调研 - 明确目标、受众、期望
  2. 主题确定 - 提炼核心概念、slogan
  3. 方案设计 - 流程、内容、形式设计
  4. 资源整合 - 场地、人员、物料、供应商
  5. 执行落地 - 现场管理、流程把控
  6. 复盘总结 - 效果评估、经验沉淀

三、活动执行标准操作流程（SOP）

3.1 开幕式SOP

时间轴：

  • T-2小时：所有工作人员到位
  • T-1小时：嘉宾签到，引导入座
  • T-30分钟：最后检查（音响、灯光、LED）
  • T-10分钟：主持人暖场
  • T-0：正式开始
  • T+30分钟：开幕式结束，引导参观

人员配置：

  • 总指挥：1人
  • 签到组：3-5人
  • 礼仪组：4-6人
  • 音响灯光：2人
  • 摄影摄像：2-3人
  • 机动人员：2人

3.2 展览期间SOP

每日流程：

  • 08:00 工作人员到岗，开馆准备
  • 08:30 展商到位，展位检查
  • 09:00 正式开馆
  • 12:00 午间轮班
  • 17:00 观众离场
  • 17:30 展商整理
  • 18:00 闭馆，安全检查

四、风险管理与应急预案

4.1 常见风险类型

安全风险

风险概率影响预防措施应急预案
踩踏事故低极高限流、单向通行、安保立即疏散、医疗救援
火灾低极高禁烟、灭火器、通道疏散、报警、灭火
设备故障中中备用设备、提前检测切换备用、暂停活动
食品安全低高资质审查、留样送医、封存、调查

运营风险

风险概率影响预防措施应急预案
嘉宾取消中中备选嘉宾、录播调整议程、替补上场
展商缺席中中押金制度、确认函调整展位、替补展商
人流不足中高多渠道宣传、优惠加大推广、现场引流
天气恶劣中高关注预报、室内备选启用备用方案

4.2 应急预案模板

大客流应急预案

触发条件：现场人数达到最大承载量的80%

响应措施：

  1. 启动限流措施，暂停入场
  2. 开放备用通道，加速疏散
  3. 增派安保人员，维持秩序
  4. 通过广播、LED引导人流
  5. 必要时联系公安支援

突发医疗事件预案

触发条件：现场人员突发疾病或受伤

响应措施：

  1. 立即通知现场医疗点
  2. 疏散围观人员，保持通风
  3. 医护人员现场处置
  4. 必要时拨打120送医
  5. 记录事件，留存资料

医疗资源配置：

  • 医疗点：每1万㎡至少1个
  • 医护人员：每5000人至少1名
  • 急救设备：AED、担架、急救箱

五、活动风险管理专题（8月27日新增）

5.1 风险分类与评估

六大风险类型：

  • 安全风险：人员安全、设施安全、消防安全、食品安全
  • 技术风险：设备故障、网络问题、电力问题、软件问题
  • 天气风险：极端天气、自然灾害、交通影响
  • 人员风险：关键人员缺席、人员不足、人员冲突、健康问题
  • 财务风险：预算超支、收入不足、资金链断裂、汇率风险
  • 舆情风险：负面报道、公关危机、品牌形象、法律纠纷

5.2 风险矩阵评估法

影响程度低(1)中(2)高(3)极高(4)
极高概率(4)中高极高极高
高概率(3)低中高极高
中概率(2)低低中高
低概率(1)低低低中

5.3 应急预案编制要点

  • 应急指挥部：总指挥、副总指挥、各职能小组负责人
  • 职能小组：安保组、医疗组、技术组、公关组、后勤组
  • 响应级别：一级响应（重大）、二级响应（较大）、三级响应（一般）
  • 预案演练：大型活动前1周至少1次，中型活动前3天至少1次

六、会展搭建与现场管理专题（8月27日新增）

6.1 展台搭建流程

时间管控标准：

  • 小型展台（36㎡以内）：1-2天
  • 中型展台（36-100㎡）：2-3天
  • 大型展台（100㎡以上）：3-5天
  • 特装展台：根据复杂度确定

6.2 现场管理要点

管理模块关键要点人员配置
签到管理电子签到、资料领取、引导入场每台2-3人
引导管理标识系统、引导人员、电子引导关键节点配置

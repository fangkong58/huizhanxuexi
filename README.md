## 📝 使用说明

### 周报制作流程
1. 每周日复制 `模板/周报模板.md` 到 `周报/` 目录
2. 重命名为 `2026年第XX周周报（M.DD-M.DD）.md`
3. 填写本周活动信息和行业分析
4. 为重点活动生成汇报图片

### 汇报图片生成流程
1. 复制 `模板/活动汇报图片模板.html` 或参考已有的汇报图HTML
2. 修改活动信息、数据、亮点等
3. 使用 `wkhtmltoimage` 命令生成PNG：
   ```bash
   wkhtmltoimage --width 1280 --height 1600 --quality 95 --format png \
     "file:///path/to/汇报图.html" "/path/to/汇报图.png"
   ```

### 南京市活动跟踪
1. 每周更新 `南京市活动专项跟踪.md`
2. 关注场馆档期变化
3. 收集活动信息和图片素材

# 会议会展行业知识库

## 一、活动策划核心方法论

### 1.1 5W2H分析法
| 要素 | 内容 | 关键问题 |
|------|------|----------|
| Why | 活动目的 | 为什么要办这个活动？ |
| What | 活动主题 | 活动是什么？核心内容是什么？ |
| Who | 参与人员 | 谁来参加？目标受众是谁？ |
| When | 时间安排 | 什么时候办？持续多久？ |
| Where | 地点选择 | 在哪里办？场地要求？ |
| How | 执行方式 | 怎么办？流程是什么？ |
| How much | 预算 | 花多少钱？投入产出比？ |

### 1.2 活动策划六步法
1. **需求调研** - 明确目标、受众、期望
2. **主题确定** - 提炼核心概念、slogan
3. **方案设计** - 流程、内容、形式设计
4. **资源整合** - 场地、人员、物料、供应商
5. **执行落地** - 现场管理、流程把控
6. **复盘总结** - 效果评估、经验沉淀

## 三、活动执行标准操作流程（SOP）

### 3.1 开幕式SOP
```
时间轴：
- T-2小时：所有工作人员到位
- T-1小时：嘉宾签到，引导入座
- T-30分钟：最后检查（音响、灯光、LED）
- T-10分钟：主持人暖场
- T-0：正式开始
- T+30分钟：开幕式结束，引导参观

人员配置：
- 总指挥：1人
- 签到组：3-5人
- 礼仪组：4-6人
- 音响灯光：2人
- 摄影摄像：2-3人
- 机动人员：2人
```

### 3.2 展览期间SOP
```
每日流程：
08:00 工作人员到岗，开馆准备
08:30 展商到位，展位检查
09:00 正式开馆
12:00 午间轮班
17:00 观众离场
17:30 展商整理
18:00 闭馆，安全检查

关键检查点：
□ 安保人员到位
□ 保洁人员到位
□ 咨询服务台就绪
□ 医疗点就绪
□ 应急通道畅通
```

### 3.3 撤展SOP
```
时间安排：
- 最后一天18:00开始撤展
- 分区域、分时段进行
- 优先撤特装展位
- 标准展位次日完成

注意事项：
□ 办理出门证
□ 检查物品损坏
□ 清理垃圾
□ 场地验收
□ 押金退还
```

## 四、风险管理与应急预案

### 4.1 常见风险类型

#### 安全风险
| 风险 | 概率 | 影响 | 预防措施 | 应急预案 |
|------|------|------|----------|----------|
| 踩踏事故 | 低 | 极高 | 限流、单向通行、安保 | 立即疏散、医疗救援 |
| 火灾 | 低 | 极高 | 禁烟、灭火器、通道 | 疏散、报警、灭火 |
| 设备故障 | 中 | 中 | 备用设备、提前检测 | 切换备用、暂停活动 |
| 食品安全 | 低 | 高 | 资质审查、留样 | 送医、封存、调查 |

#### 运营风险
| 风险 | 概率 | 影响 | 预防措施 | 应急预案 |
|------|------|------|----------|----------|
| 嘉宾取消 | 中 | 中 | 备选嘉宾、录播 | 调整议程、替补上场 |
| 展商缺席 | 中 | 中 | 押金制度、确认函 | 调整展位、替补展商 |
| 人流不足 | 中 | 高 | 多渠道宣传、优惠 | 加大推广、现场引流 |
| 天气恶劣 | 中 | 高 | 关注预报、室内备选 | 启用备用方案 |

#### 法律风险
| 风险 | 概率 | 影响 | 预防措施 | 应急预案 |
|------|------|------|----------|----------|
| 审批未通过 | 低 | 极高 | 提前申请、合规审查 | 延期、调整方案 |
| 知识产权纠纷 | 中 | 高 | 授权确认、原创声明 | 下架、协商、法律应对 |
| 合同纠纷 | 中 | 中 | 规范合同、律师审核 | 协商、调解、诉讼 |

### 4.2 应急预案模板

#### 大客流应急预案
```
触发条件：现场人数达到最大承载量的80%

响应措施：
1. 启动限流措施，暂停入场
2. 开放备用通道，加速疏散
3. 增派安保人员，维持秩序
4. 通过广播、LED引导人流
5. 必要时联系公安支援

通讯联络：
- 总指挥：XXX 电话：XXX
- 安保负责人：XXX 电话：XXX
- 公安联络人：XXX 电话：XXX
```

#### 突发医疗事件预案
```
触发条件：现场人员突发疾病或受伤

响应措施：
1. 立即通知现场医疗点
2. 疏散围观人员，保持通风
3. 医护人员现场处置
4. 必要时拨打120送医
5. 记录事件，留存资料

医疗资源配置：
- 医疗点：每1万㎡至少1个
- 医护人员：每5000人至少1名
- 急救设备：AED、担架、急救箱
```
